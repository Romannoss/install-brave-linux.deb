# install brave linux .deb

Script para instalar o browser brave no linux .deb.  
Para quem não gosta de usar pacote snap/flatpak e quer usar o brave versão .deb no ubuntu.

Os comandos no script são os mesmos da pag.
https://brave.com/linux/

Segue os passos para executar o script para instalação.

1) baixar o script
2) verifica se está com permissão, botão direito e opção propriedade ou use o comando no terminal "chmod 777 install-brave.sh"
3) depois execute o script pelo explorador de arquivos ou pelo terminal com o comando "sudo ./install-brave.sh"
